# weldmark

Weld validation gates for mark inputs before they hit prod.

**Site:** https://theworker02.github.io/weldmark/

## Install / run

```bash
git clone https://github.com/theworker02/weldmark.git
cd weldmark
node src/cli.js
node --test
```
